# Optikit AI Content Studio

Optikit adalah alat otomatisasi konten berbasis AI yang dirancang khusus untuk para affiliate marketer. Alat ini membantu kreator mempercepat proses pembuatan konten yang high-conversion.

## 🚀 Fitur Utama
* AI Content Generation: Membuat caption, skrip video (15-30 detik), dan hashtag yang dioptimalkan untuk performa terbaik di media sosial.
* Image Optimization: Kompresi gambar otomatis langsung dari sisi klien (browser) untuk memastikan kecepatan akses website yang maksimal.
* SEO Optimized: Menggunakan struktur metadata modern dan Schema Markup untuk memastikan keterbacaan yang optimal di mesin pencari.
* Serverless Architecture: Dibangun menggunakan Cloudflare Pages dan Cloudflare Workers untuk efisiensi dan skalabilitas tinggi.

## 🛠️ Stack Teknologi
* Frontend: HTML5, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+).
* Hosting: Cloudflare Pages.
* Backend/Logic: Cloudflare Workers (untuk pemrosesan AI).
* Version Control: GitHub.

## 💡 Mengapa Proyek Ini Dibuat?
Proyek ini dikembangkan untuk memecahkan masalah efisiensi waktu bagi affiliate marketer dalam memproduksi konten visual yang menarik dan teks promosi yang persuasif.
